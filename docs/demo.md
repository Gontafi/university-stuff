# Демонстрация

1. Выполнить `make up`, открыть baseline и FT по напечатанным адресам. Зарегистрировать студента, внести платёж и оценку, сформировать выписку. Проверить `balance_mismatches = 0`.
2. Выполнить `make demo`. Скрипт создаёт отдельного студента для каждого эксперимента и сравнивает три сбоя в обоих режимах. При выполнении показывать список pod:

   ```sh
   minikube -p university-ft kubectl -- -n university-ft get pods -o wide --watch
   ```

3. **Application crash:** скрипт принудительно удаляет одну копию payment без grace period. Показать её замену Kubernetes. У FT остаётся другая копия; краткие ошибки во время переключения возможны. У baseline до появления новой копии обслуживать запросы некому.
4. **Service timeout:** сервис records задерживает запросы на 2 s. Baseline нарушает SLA 1.5 s. FT ограничивает попытку до 700 ms, открывает circuit breaker и может выдать сохранённую выписку с `X-Degraded`. После снятия задержки half-open проба разрешает обычные обращения.
5. **Interrupted payment:** искусственный отказ между ledger insert и обновлением баланса. Baseline оставляет несогласованные данные и при повторе добавляет лишнюю запись. FT откатывает незавершённую транзакцию и после повторной отправки записывает только один платёж с тем же ключом.
6. Показать `summary.json`, исходные JSON-запросы и логи в напечатанном каталоге. Сопоставить failed requests, recovered requests, MTTR и consistency. Значение `null` означает отсутствие достаточного наблюдения, а не нулевое время восстановления.
7. Для инфраструктурной части отдельно запустить `make backup` и `make restore`. Показать checksum, успешный `pg_restore`, таблицы восстановленной базы и нулевое число несогласованных балансов. Первичная база не удаляется; восстановление выполняется в `recovery_verify`.

Для оставшихся обязательных сценариев выполнить `make experiments`: временно отключается PostgreSQL, останавливается worker m02 на 50 s и создаётся нагрузка из 80 клиентов. Во время экспериментов не запускать второй набор и не изменять данные через UI.
